# Night Atlas — International Urban Skyglow & Municipal Lighting Mitigation Lab

## Quick Start
Because the app uses ES modules (`js/app.js`, `js/map.js`, `js/physics.js`, `js/presets.js`), run a local static server from inside this folder:

```bash
cd "/Users/mark/Desktop/Night Atlas site"
python3 -m http.server 8765
```

Then open `http://localhost:8765` in Safari or Chrome.
